Goko实训：**室内智能监测系统的设计和实现**

硬件(利用stm32芯片完成)：
  - 温湿度传感器采集室内温湿度
  - 光照传感器采集光照
  - 摄像头 -> 实时查看室内画面
  - 继电器控制室内灯光
  - 舵机模拟控制窗帘
  - 蜂鸣器用于报警
  - esp8266用于远程发送命令控制和传输数据

前端：
  - 网页可实时查看摄像头画面和传感器数据
  - 识别到有画面有异常情况发送信息通知
